Cómo usar tu API Key

  1. Guarda tu API Key en el backend de tu aplicación.
  2. No la pongas directamente en JavaScript público del navegador.
  3. Envía SMS llamando al endpoint público de Supabase con el header X-API-Key.
  4. Usa Idempotency-Key para evitar envíos duplicados.
